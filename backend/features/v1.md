# Post-Processing Module — Audio Enhancement Pipeline

## Overview

The audio post-processing module runs **after the model returns 2 files** (vocal + instrumental). Objective: remove artifacts, reduce noise, normalize output quality.

**Designed as an optional feature** — users can enable/disable it via API parameter `enhance: true/false`.

```
POST /api/v1/separate
{
  "model": "bs_roformer",
  "enhance": true,           ← toggle post-processing
  "enhance_level": "medium"  ← light | medium | aggressive
}
```

---

## Why is post-processing needed?

Raw output from the separation model always has artifacts at various levels:

| Artifact | Description | Cause |
|----------|--------|-------------|
| Musical noise | Bubbling sounds, gurgling | Spectrogram mask not smooth, zeroing creates time-frequency discontinuities |
| Spectral bleeding | Audio leakage between stems | Model mask prediction not accurate in frequency overlap regions |
| Phase swirling | Vocal sounds warped, unnatural | Phase mismatch during overlap-add resynthesis |
| Chunk boundary clicks | Clicks/pops between segments | Crossfade between chunks not smooth |
| High-frequency loss | Loss of sibilance (sounds "s", "t") | Model weak in high frequencies, or training data bandwidth-limited |
| Silent passage noise | Small noise in silent sections | Model doesn't perfect zero when no target source |
| Loudness inconsistency | Uneven output volume | Model doesn't normalize, dynamic range varies |

### Core Pipeline (`pipeline.py`)

```python
import numpy as np
import time
import logging
from dataclasses import dataclass
from enum import Enum
from typing import Optional

logger = logging.getLogger(__name__)


class EnhanceLevel(str, Enum):
    LIGHT = "light"
    MEDIUM = "medium"
    AGGRESSIVE = "aggressive"


@dataclass
class PostProcessResult:
    vocal: np.ndarray
    instrumental: np.ndarray
    sr: int
    steps_applied: list[str]
    total_duration_ms: float
    metrics: dict  # before/after SNR, loudness, etc.


class AudioPostProcessor:
    """
    Post-processing pipeline for separated audio.
    Runs as optional step after model inference.
    """

    def __init__(self, sr: int = 44100, level: EnhanceLevel = EnhanceLevel.MEDIUM):
        self.sr = sr
        self.level = level
        self._steps = self._build_steps()

    def _build_steps(self) -> list:
        """Build pipeline based on enhancement level."""
        from .silence_gate import apply_silence_gate
        from .spectral_denoise import apply_spectral_denoise
        from .highfreq_restore import restore_high_frequencies
        from .artifact_smooth import smooth_artifacts
        from .mixture_consistency import enforce_consistency
        from .loudness_norm import normalize_loudness

        steps = []

        # Light: gate + denoise + loudness
        steps.append(("silence_gate", apply_silence_gate))
        steps.append(("spectral_denoise", apply_spectral_denoise))

        if self.level in (EnhanceLevel.MEDIUM, EnhanceLevel.AGGRESSIVE):
            steps.append(("highfreq_restore", restore_high_frequencies))
            steps.append(("artifact_smooth", smooth_artifacts))
            steps.append(("mixture_consistency", enforce_consistency))

        steps.append(("loudness_norm", normalize_loudness))

        if self.level == EnhanceLevel.AGGRESSIVE:
            from .ai_denoise import apply_ai_denoise
            steps.append(("ai_denoise", apply_ai_denoise))

        return steps

    def process(
        self,
        vocal: np.ndarray,
        instrumental: np.ndarray,
        original: Optional[np.ndarray] = None,
    ) -> PostProcessResult:
        """
        Run the entire pipeline.

        Args:
            vocal: Raw vocal output from model, shape (channels, samples) or (samples,)
            instrumental: Raw instrumental output from model
            original: Original mixture (needed for mixture consistency check)

        Returns:
            PostProcessResult with enhanced audio and metadata
        """
        start = time.time()
        steps_applied = []

        for step_name, step_fn in self._steps:
            try:
                step_start = time.time()

                if step_name == "mixture_consistency" and original is not None:
                    vocal, instrumental = step_fn(
                        vocal, instrumental, original, sr=self.sr
                    )
                elif step_name == "mixture_consistency" and original is None:
                    logger.warning("Skipping mixture_consistency: original audio not provided")
                    continue
                else:
                    # Most steps process each stem separately
                    vocal = step_fn(vocal, sr=self.sr, stem_type="vocal", level=self.level)
                    instrumental = step_fn(
                        instrumental, sr=self.sr, stem_type="instrumental", level=self.level
                    )

                step_ms = (time.time() - step_start) * 1000
                steps_applied.append({"name": step_name, "duration_ms": round(step_ms, 1)})
                logger.info(f"[PostProcess] {step_name} completed in {step_ms:.1f}ms")

            except Exception as e:
                logger.error(f"[PostProcess] {step_name} failed: {e}")
                # Post-processing failure should NOT fail the entire task
                # Just skip the step and continue
                steps_applied.append({"name": step_name, "error": str(e)})
                continue

        total_ms = (time.time() - start) * 1000

        return PostProcessResult(
            vocal=vocal,
            instrumental=instrumental,
            sr=self.sr,
            steps_applied=steps_applied,
            total_duration_ms=round(total_ms, 1),
            metrics=self._compute_metrics(vocal, instrumental),
        )

    def _compute_metrics(self, vocal: np.ndarray, instrumental: np.ndarray) -> dict:
        """Compute metrics after post-processing."""
        return {
            "vocal_peak_db": round(20 * np.log10(np.max(np.abs(vocal)) + 1e-10), 2),
            "instrumental_peak_db": round(20 * np.log10(np.max(np.abs(instrumental)) + 1e-10), 2),
            "vocal_rms_db": round(20 * np.log10(np.sqrt(np.mean(vocal**2)) + 1e-10), 2),
            "instrumental_rms_db": round(20 * np.log10(np.sqrt(np.mean(instrumental**2)) + 1e-10), 2),
        }
```

### Step 1: Silence Gate (`silence_gate.py`)

Reduce noise in silent sections by detecting and suppressing frames with low energy.

```python
import numpy as np
from scipy.signal import medfilt


def apply_silence_gate(
    audio: np.ndarray,
    sr: int = 44100,
    stem_type: str = "vocal",
    level: str = "medium",
    threshold_db: float = -50.0,
    attack_ms: float = 5.0,
    release_ms: float = 50.0,
) -> np.ndarray:
    """
    Noise gate based on energy threshold.
    Sections with energy below threshold will be attenuated (not zeroed completely to avoid clicks).

    Args:
        threshold_db: Energy threshold (dB). Lower = less gating.
                      Vocal should use -50dB, instrumental -55dB.
    """
    if stem_type == "vocal":
        threshold_db = -50.0
    else:
        threshold_db = -55.0  # Instrumental gates less, preserves reverb tail

    # Calculate RMS energy per frame
    frame_length = int(sr * 0.025)  # 25ms frames
    hop_length = int(sr * 0.010)    # 10ms hop

    # Handle mono or stereo
    is_stereo = audio.ndim == 2
    if is_stereo:
        mono = np.mean(audio, axis=0)
    else:
        mono = audio

    n_frames = 1 + (len(mono) - frame_length) // hop_length
    energy_db = np.full(n_frames, -100.0)

    for i in range(n_frames):
        start = i * hop_length
        frame = mono[start : start + frame_length]
        rms = np.sqrt(np.mean(frame**2) + 1e-10)
        energy_db[i] = 20 * np.log10(rms)

    # Smooth energy curve
    energy_db = medfilt(energy_db, kernel_size=5)

    # Create gain envelope (0 = gate closed, 1 = gate open)
    gate = np.where(energy_db > threshold_db, 1.0, 0.05)  # 0.05 instead of 0 to avoid clicks

    # Attack/release smoothing
    attack_samples = max(1, int(attack_ms / 10))
    release_samples = max(1, int(release_ms / 10))

    smoothed_gate = np.copy(gate)
    for i in range(1, len(smoothed_gate)):
        if smoothed_gate[i] > smoothed_gate[i - 1]:
            # Attack: gate opening
            smoothed_gate[i] = min(1.0, smoothed_gate[i - 1] + 1.0 / attack_samples)
        else:
            # Release: gate closing
            smoothed_gate[i] = max(0.05, smoothed_gate[i - 1] - 1.0 / release_samples)

    # Interpolate gate envelope to sample level
    gate_samples = np.interp(
        np.arange(mono.shape[-1]),
        np.arange(n_frames) * hop_length,
        smoothed_gate,
    )

    if is_stereo:
        return audio * gate_samples[np.newaxis, :]
    return audio * gate_samples
```

### Step 2: Spectral Noise Reduction (`spectral_denoise.py`)

```python
import noisereduce as nr
import numpy as np


def apply_spectral_denoise(
    audio: np.ndarray,
    sr: int = 44100,
    stem_type: str = "vocal",
    level: str = "medium",
) -> np.ndarray:
    """
    Spectral gating noise reduction.
    Parameters tuned separately for vocal vs instrumental.
    """
    # Config by stem type and level
    configs = {
        ("vocal", "light"):       {"stationary": False, "prop_decrease": 0.4, "n_fft": 2048},
        ("vocal", "medium"):      {"stationary": False, "prop_decrease": 0.6, "n_fft": 2048},
        ("vocal", "aggressive"):  {"stationary": False, "prop_decrease": 0.8, "n_fft": 2048},
        ("instrumental", "light"):       {"stationary": True, "prop_decrease": 0.3, "n_fft": 2048},
        ("instrumental", "medium"):      {"stationary": True, "prop_decrease": 0.5, "n_fft": 2048},
        ("instrumental", "aggressive"):  {"stationary": True, "prop_decrease": 0.7, "n_fft": 2048},
    }

    config = configs.get((stem_type, level), configs[("vocal", "medium")])

    # noisereduce processes mono, so separate channels if stereo
    if audio.ndim == 2:
        result = np.stack([
            nr.reduce_noise(y=audio[ch], sr=sr, **config)
            for ch in range(audio.shape[0])
        ])
    else:
        result = nr.reduce_noise(y=audio, sr=sr, **config)

    return result
```

### Step 3: High-Frequency Restoration (`highfreq_restore.py`)

```python
import numpy as np
from scipy.signal import butter, sosfilt


def restore_high_frequencies(
    audio: np.ndarray,
    sr: int = 44100,
    stem_type: str = "vocal",
    level: str = "medium",
    cutoff_detect_threshold_db: float = -40.0,
) -> np.ndarray:
    """
    Detect if model has cut high frequencies (typically around ~16kHz)
    and mirror high-frequency portion to restore sibilance.

    Only applies if bandwidth limitation is detected.
    """
    if sr < 44100:
        return audio  # Don't restore if sample rate is low

    # Analyze spectrum to detect cutoff
    if audio.ndim == 2:
        mono = np.mean(audio, axis=0)
    else:
        mono = audio

    # FFT to find cutoff frequency
    n_fft = 8192
    spectrum = np.abs(np.fft.rfft(mono[:n_fft * 4]))
    freqs = np.fft.rfftfreq(n_fft * 4, d=1.0 / sr)

    # Calculate average energy by band
    band_size = sr // 1000  # ~1kHz per band
    n_bands = len(spectrum) // band_size

    band_energy_db = []
    for i in range(n_bands):
        band = spectrum[i * band_size : (i + 1) * band_size]
        energy = np.mean(band**2)
        band_energy_db.append(20 * np.log10(energy + 1e-10))

    # Detect cutoff: find first band with energy drop > threshold
    cutoff_band = None
    if len(band_energy_db) > 10:
        avg_low = np.mean(band_energy_db[2:8])  # 2-8 kHz reference
        for i in range(8, len(band_energy_db)):
            if band_energy_db[i] < avg_low + cutoff_detect_threshold_db:
                cutoff_band = i
                break

    if cutoff_band is None or cutoff_band * 1000 > 20000:
        return audio  # No cutoff detected, skip

    cutoff_freq = cutoff_band * 1000
    mirror_from = max(cutoff_freq - 2000, 8000)  # Mirror from 2kHz below cutoff

    # Bandpass filter to extract portion to mirror
    nyq = sr / 2
    low = mirror_from / nyq
    high = min(cutoff_freq / nyq, 0.99)

    if low >= high or high >= 1.0:
        return audio

    sos = butter(4, [low, high], btype="band", output="sos")

    def process_channel(ch_audio):
        mirror_band = sosfilt(sos, ch_audio)
        # Frequency shift up via modulation
        t = np.arange(len(mirror_band)) / sr
        shift_freq = cutoff_freq - mirror_from
        shifted = mirror_band * np.cos(2 * np.pi * shift_freq * t)
        # Mix lightly into original (-12dB for natural sound)
        gain = 10 ** (-12 / 20)
        return ch_audio + shifted * gain

    if audio.ndim == 2:
        return np.stack([process_channel(audio[ch]) for ch in range(audio.shape[0])])
    return process_channel(audio)
```

### Step 4: Artifact Smoothing (`artifact_smooth.py`)

```python
import numpy as np
from scipy.ndimage import median_filter


def smooth_artifacts(
    audio: np.ndarray,
    sr: int = 44100,
    stem_type: str = "vocal",
    level: str = "medium",
) -> np.ndarray:
    """
    Remove musical noise by smoothing spectrogram mask.
    Use median filter on magnitude spectrogram then apply soft mask.
    """
    n_fft = 2048
    hop_length = 512

    # Smooth strength by level
    filter_size = {"light": 3, "medium": 5, "aggressive": 7}.get(level, 5)

    def process_channel(ch_audio):
        # STFT
        from scipy.signal import stft, istft

        f, t, Zxx = stft(ch_audio, fs=sr, nperseg=n_fft, noverlap=n_fft - hop_length)
        magnitude = np.abs(Zxx)
        phase = np.angle(Zxx)

        # Median filter on magnitude to smooth musical noise
        mag_smoothed = median_filter(magnitude, size=(filter_size, filter_size))

        # Soft mask: ratio between smoothed and original
        mask = mag_smoothed / (magnitude + 1e-10)
        mask = np.clip(mask, 0.0, 1.0)

        # Smooth mask edges
        mask = median_filter(mask, size=(3, 3))

        # Apply mask
        Zxx_clean = magnitude * mask * np.exp(1j * phase)

        # iSTFT
        _, result = istft(Zxx_clean, fs=sr, nperseg=n_fft, noverlap=n_fft - hop_length)

        # Trim or pad to original length
        if len(result) > len(ch_audio):
            result = result[: len(ch_audio)]
        elif len(result) < len(ch_audio):
            result = np.pad(result, (0, len(ch_audio) - len(result)))

        return result

    if audio.ndim == 2:
        return np.stack([process_channel(audio[ch]) for ch in range(audio.shape[0])])
    return process_channel(audio)
```

### Step 5: Mixture Consistency (`mixture_consistency.py`)

```python
import numpy as np


def enforce_consistency(
    vocal: np.ndarray,
    instrumental: np.ndarray,
    original: np.ndarray,
    sr: int = 44100,
) -> tuple[np.ndarray, np.ndarray]:
    """
    Ensure vocal + instrumental ≈ original.
    Distribute residual error to the stem with lower energy at each sample.

    This is an important constraint because post-processing steps
    can cause the sum of 2 stems to deviate from the original.
    """
    # Trim/pad to same length
    min_len = min(vocal.shape[-1], instrumental.shape[-1], original.shape[-1])
    if vocal.ndim == 2:
        vocal = vocal[:, :min_len]
        instrumental = instrumental[:, :min_len]
        original = original[:, :min_len]
    else:
        vocal = vocal[:min_len]
        instrumental = instrumental[:min_len]
        original = original[:min_len]

    # Calculate residual
    current_sum = vocal + instrumental
    residual = original - current_sum

    # Distribute residual based on energy ratio
    vocal_energy = np.abs(vocal) + 1e-10
    inst_energy = np.abs(instrumental) + 1e-10
    total_energy = vocal_energy + inst_energy

    vocal_ratio = vocal_energy / total_energy
    inst_ratio = inst_energy / total_energy

    # Stem with higher energy receives more residual
    # This is more natural because error typically occurs in dominant parts
    vocal_corrected = vocal + residual * vocal_ratio
    instrumental_corrected = instrumental + residual * inst_ratio

    return vocal_corrected, instrumental_corrected
```

### Step 6: Loudness Normalization (`loudness_norm.py`)

```python
import numpy as np
import pyloudnorm as pyln


def normalize_loudness(
    audio: np.ndarray,
    sr: int = 44100,
    stem_type: str = "vocal",
    level: str = "medium",
    target_lufs: float = -14.0,
) -> np.ndarray:
    """
    Normalize loudness per ITU-R BS.1770 (LUFS).
    Target -14 LUFS is suitable for streaming platforms.

    Vocal: -14 LUFS (default)
    Instrumental: -16 LUFS (slightly lower, sounds natural when remixed)
    """
    if stem_type == "instrumental":
        target_lufs = -16.0

    meter = pyln.Meter(sr)

    # pyloudnorm expects (samples, channels) format
    if audio.ndim == 2:
        audio_for_meter = audio.T  # (channels, samples) -> (samples, channels)
    else:
        audio_for_meter = audio

    try:
        current_loudness = meter.integrated_loudness(audio_for_meter)

        if np.isinf(current_loudness) or current_loudness < -70:
            # Audio too quiet or silence, skip normalization
            return audio

        normalized = pyln.normalize.loudness(audio_for_meter, current_loudness, target_lufs)

        if audio.ndim == 2:
            return normalized.T  # Back to (channels, samples)
        return normalized

    except Exception:
        # Fallback: simple peak normalization
        peak = np.max(np.abs(audio))
        if peak > 0:
            return audio * (0.95 / peak)
        return audio
```

### Step 7: AI Denoise — Aggressive Only (`ai_denoise.py`)

```python
import numpy as np
import logging

logger = logging.getLogger(__name__)


def apply_ai_denoise(
    audio: np.ndarray,
    sr: int = 44100,
    stem_type: str = "vocal",
    level: str = "aggressive",
) -> np.ndarray:
    """
    Run pretrained denoise model (MelBand RoFormer Denoise) on separated stem.
    Only for aggressive mode due to GPU inference time cost (~5-10s).

    Model: denoise_mel_band_roformer_aufr33_sdr_27.9959.ckpt
    Source: ZFTurbo/Music-Source-Separation-Training

    Called via Model Serving API (same service as separation model).
    """
    if level != "aggressive":
        return audio

    try:
        import requests
        import soundfile as sf
        import tempfile
        import os

        MODEL_SERVING_URL = os.environ.get("MODEL_SERVING_URL", "http://model-serving:8001")

        # Write audio to temp file
        with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as tmp:
            if audio.ndim == 2:
                sf.write(tmp.name, audio.T, sr)
            else:
                sf.write(tmp.name, audio, sr)
            tmp_path = tmp.name

        # Call model serving endpoint for denoise
        with open(tmp_path, "rb") as f:
            response = requests.post(
                f"{MODEL_SERVING_URL}/denoise",
                files={"file": ("audio.wav", f, "audio/wav")},
                data={"model": "mel_band_roformer_denoise"},
                timeout=60,
            )

        if response.status_code == 200:
            # Read result
            with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as out_tmp:
                out_tmp.write(response.content)
                out_path = out_tmp.name

            denoised, _ = sf.read(out_path)
            os.unlink(out_path)

            if denoised.ndim == 2:
                denoised = denoised.T  # Back to (channels, samples)

            logger.info(f"[AI Denoise] Applied successfully for {stem_type}")
            return denoised
        else:
            logger.warning(f"[AI Denoise] Model serving returned {response.status_code}, skipping")
            return audio

    except Exception as e:
        logger.error(f"[AI Denoise] Failed: {e}, returning original")
        return audio

    finally:
        # Cleanup temp files
        try:
            os.unlink(tmp_path)
        except Exception:
            pass
```

```python
        update_task_status(task_id, "failed", str(e))
```

## Tuning Guide

| Parameter | Vocal | Instrumental | Notes |
|-----------|-------|-------------|---------|
| Silence gate threshold | -50 dB | -55 dB | Instrumental needs to preserve reverb tail |
| Spectral denoise prop_decrease | 0.4–0.8 | 0.3–0.7 | Higher = cleaner but loses detail |
| Spectral denoise stationary | False | True | Vocal is dynamic, instrumental more stable |
| Artifact smooth filter_size | 5 | 5 | Increase if too much musical noise |
| Loudness target | -14 LUFS | -16 LUFS | Suitable for streaming platforms |
| High-freq mirror gain | -12 dB | -12 dB | Too high will sound artificial |

## Production Notes

1. **Post-processing failure MUST NOT fail task** — always wrap in try/except, skip failed step
2. **Log each step in detail** — duration, metrics before/after — for debugging and tuning
3. **Cache AI denoise model** — load once when container starts, not per-request
4. **Monitor VRAM** — AI denoise uses additional ~2-3GB VRAM, ensure sufficient capacity
5. **A/B testing** — let users listen to raw vs enhanced to validate actual quality
6. **Config via environment** — all thresholds should be configurable via environment variables
